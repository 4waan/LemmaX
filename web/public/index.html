What each line in that terminal did

Seven MCP tools, one contract on Monad, one public auditor.

  1. lemma_assess

    Odds with error bars

    Measured outcomes feed a Beta posterior: a hit rate and its 95% range. Too little evidence and the answer is unknown, never a guess.

  2. lemma_assess

    Cost to an answer

    Each offer is priced against the agent's own fallback, ranked, and skipped when buying would cost more.

  3. lemma_quote_attempt

    One signature is the whole bill

    The bill's EIP-712 hash is the nonce of a USDC authorization. Payees, caps, checker and deadlines are signed together and can never be replayed.

  4. wallet_sign_bill

    A wallet that reads the record

    The guard checks that the auditor has seen the last settlement and that no one on the bill has a finding. Then the policy signs that one hash.

  5. lemma_fund_attempt

    Final inside one tool call

    The call streams Monad's commit states and returns at Verified, so the search only starts on money that cannot move back.

  6. lemma_deliver_attempt

    The result priced apart from trying

    A named checker signs the verdict. One settlement pays the search on a hit, the fixed costs either way, and returns the rest.

lemma_verify_attempt rebuilds any attempt from Monad's logs against the hash-pinned rulebook. Only settled attempts write reputation to ERC-8004.
